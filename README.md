This project is a classic broadsheet-style front page that summarizes the world news of Sunday, 22 November 2026.

### Stories
1. Rutte vows NATO will defend 'every inch' of Poland
2. Iranian missiles strike US air defences in Bahrain
3. EU and Indonesia sign landmark trade deal
4. COP31 deadlocked as draft drops fossil fuels
5. 'El Chapo Isidro' captured in Mexico
6. Russian strike kills 2 at Lviv station
7. Ireland stun world champions 20–17

### Build
The front page image is generated by `poster.html` which is screenshotted into `entry.png` using Playwright. `main.ts` copies this image to the output directory.

### Sources
BBC, Reuters, AP, AFP, NYT.

### Run-it
`npm install playwright`
`node ni22r3-shots.mjs`
`node main.ts`
